# 10 · 字体资源实测：真正的体积大头

> 实测日期：2026-09-24
> 方法：`env/tools/net-measure.js` —— 真实浏览器加载 + 滚动整页，记录所有请求的传输体积
> 结论：**字体占页面总传输的 44%，是主题侧最大的单项开销。此前文档 02 严重低估了它。**

---

## 一、为什么之前的估算漏了字体

文档 02 的统计方法是「抓 HTML，提取其中的资源 URL，逐个 curl 测体积」。
这个方法有个盲区：

> **webfont 的字体文件不在 HTML 里。**
>
> CSS 通过 `@font-face { src: url(...woff2) }` 引用字体，浏览器是**解析 CSS 后**、
> 按需（`unicode-range` 命中）才去下载的。HTML 里根本找不到这些 URL。

所以文档 02 记的「FontAwesome 20.5 KB」只是那个 CSS 的体积，
真正的大头 —— 三个字体文件 295 KB —— 完全没进统计。

**这也是「为什么本地实测手感比文档描述的重得多」的原因。**

---

## 二、实测结果（首页，浏览器加载整页 + 滚动）

```
请求总数：48    传输合计：1962.9 KB
```

**字体占页面总传输的 44%。**

对比此前文档 02 的记载：「FontAwesome 20.5 KB」—— 实际开销是它的 **15 倍**。

## 三、FontAwesome：100 个图标 vs 2000+

### 实际用到多少

扫描主题全部代码（已排除 `opt/fields/icon/` 那个后台图标选择器的完整清单）：

```
实际用到的图标数：约 100 个
```

高频的：`fa-comment`、`fa-bookmark`、`fa-clock`、`fa-angle-right`、`fa-font`、`fa-laptop`、
`fa-guitar`、`fa-image`、`fa-eye`、`fa-lock`、`fa-bars`、`fa-play`…

### 代价

三套字体（solid / regular / brands）**295.3 KB**，只为了这 100 个图标。

### 优化空间

子集化后预计 **25 KB 以内**，可省 **约 270 KB**。

### 风险（这是关键）

**用户可以在后台把社交链接的图标改成任意 FontAwesome 图标**（选项里有图标选择器，
数据源是完整的 2000+ 清单）。所以「扫描主题代码」**无法覆盖用户配置**。

一旦配到子集之外的图标，就会显示为空白。

可能的折中：只子集化 `fa-solid`（154.5 KB）、保留 `fa-brands` 完整（115.9 KB，社交图标基本都在这里），
预计省 130 KB 左右，风险显著降低。

## 四、Google Fonts：两个中文字体

主题加载（`header.php:76-77`）：

```
fonts.googleapis.com/css?family=Noto+Serif+SC|Noto+Sans+SC|Fira+Code&display=swap
```

### 各自用在哪

| 字体 | 使用位置 | 出现次数 |
| --- | --- | --- |
| `Noto Sans SC` | `.center-text` / `.Ubuntu-font` / `.entry-content code` | 3 |
| `Fira Code, Noto Sans SC` | 代码块相关 | 3 |
| `Noto Serif SC` | `.header-info p` / `.serif` | **2** |
| `Noto Serif CJK SC, …` | `.aplayer`（播放器） | 1 |

**正文本身用的是系统字体栈**（`system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "Microsoft YaHei", …`），
Noto 只服务于上述少数元素。

### 为什么开销这么大

Google Fonts 把中文字体切成 100+ 个分片（按 `unicode-range`），
浏览器只下载「页面字符命中」的分片。中文博客正文动辄上千个不同汉字，
于是累计加载约 549 KB。

**这不完全是浪费** —— 分片机制本身是高效的（自托管一个 3500 常用字子集反而更大，
woff2 约 1.5 MB）。但**加载两个中文字体意味着这套开销翻倍**。

### 可选方向

| 方向 | 收益 | 代价 |
| --- | --- | --- |
| 去掉 `Noto Serif SC`（只 2 处用到） | 约 −275 KB | 那两处从衬线变无衬线 |
| 改用异步加载（`media="print" onload`） | 不省体积，但不阻塞首屏渲染 | 出现 FOUT（先回退字体后替换） |
| 自托管 + 子集化 | 不确定（中文动态内容难以预知） | 工程量大，可能反而更大 |
