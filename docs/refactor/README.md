## 分支约定

```
main        ── 与上游 mirai-mamori/Sakurairo 保持一致，只同步不改
relive      ── 重构工作分支（当前）
refactor/*  ── 单点改造较大时从中切子分支
```

## 提交约定

- 每个改造点一个 commit，不做大杂烩
- commit message 说明：**改了什么 / 为什么改 / 影响范围 / 如何回退**
- 涉及视觉的改动，必须附改前改后对比结论

## 注意

本目录是开发过程文档，不是主题运行所需文件。若最终要打包发布主题，可在构建时排除 `docs/`。
